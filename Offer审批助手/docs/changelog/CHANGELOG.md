# Offer审批助手 更新日志

## v1.0 (2026-04-27)

### 新增
- **双层规则库管理**：统一规则 + 个人规则，声明式 JSON 引擎（11 种运算符），行内编辑 + 开关 + 导入导出
- **配置表系统**：因子权重表（系统拟合 vs 用户覆盖）、竞企清单、稀缺岗位清单、能力标签库、分摊年限，5 个子 Tab 管理
- **样本规划向导**：4 维组合计算（国家/职级/通道/职位类型）、三档样本建议（最低/推荐/理想）、进度可视化
- **历史 Offer 学习与画像**：
  - 批量导入历史已审批 Offer（26 字段 Excel 模板）
  - 4 维强制切分计算 P25/P50/P75（严禁混算后加系数补偿）
  - 数值型画像（7 个薪酬维度）+ 条件型画像（竞对溢价/紧迫度效应/结构偏好）
  - 因子权重从历史数据自动拟合
  - 覆盖度热力图（table-based，按国家分组，颜色编码）
  - 画像白盒编辑（确认/编辑/拒绝/删除/转为个人规则）
- **8 因子 Pipeline 推荐引擎**：
  - 基线水位 / 候选人增幅 / 外部竞争 / 内部平衡 / 紧迫度 / 能力标签 / 岗位稀缺度 / 薪酬结构偏好
  - 因子独立可插拔，统一 `run()` 接口
  - 输出三档方案（保守/标准/进取），每档附总包结构明细 + 触发因子清单 + 风险徽章
- **Offer 体检报告**：合规（绿）/ 风险（黄）/ 违规（红）三栏，每项可展开看规则来源
- **审批说明三段式生成**：总包方案 / 能力匹配 / 预算与风险，方案切换实时刷新，支持单段重新生成
- **脱敏管道**：9 种策略（数值偏移/取整/文本替换/截断/哈希/日期模糊/泛化/删除/保留）
- **AI Provider 抽象层**：默认关闭，开启提示脱敏，预留 OpenAI/DeepSeek 扩展位
- **操作工具**：一键复制全文 / 导出 Markdown / 企微发送入口（预留）
- 5 个标准 Excel 模板（薪酬 14 字段 / 历史 Offer / 规则库 / 在司员工快照）
- 行业通用默认规则 6 条（带宽检查/增幅上限/红线/Base 比例/签字费/股票）

### 改进
- Dashboard 快速入口现在反映实际数据量
- 单文件 HTML 构建产出（1135 KB），所有模块内联

## v0.1 (2026-04-27)

### 新增
- 项目骨架搭建（双形态：网页版 + Electron 桌面版）
- 6 页面侧边栏布局（工作台/薪酬导入/Offer体检/规则库/习惯画像/审批说明）
- Dashboard 工作台：统计卡片 + 快速入口 + 活动流
- 薪酬导入与校验页：
  - Excel 拖拽上传，自动解析 14 个标准薪酬字段
  - 字段别名映射（兼容不同模板列名）
  - 3 个计算项自动核算（现金收入/年收入/年收入含一次性）
  - Excel 值 vs 系统计算值对比，不一致标红
  - 签字费/签字股票分摊年限可配置（默认 2 年）
  - 完整性检查 + 数值合理性检查
- IndexedDB + localStorage 本地存储封装
- 备份导出/导入还原
- Electron 主进程（完全禁止网络 + EPIPE 防护）
- build.js 单文件 HTML 合并打包脚本
