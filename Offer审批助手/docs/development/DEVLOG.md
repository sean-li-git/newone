## v1.0 — 2026-04-27

### 核心迭代内容
- 完成双层规则库（统一 + 个人）+ 配置表系统（5 个子 Tab）
- 实现样本规划向导（4 维组合计算 + 三档建议）
- 实现画像学习器（4 维强制切分 + 数值型 + 条件型 + 因子权重自动拟合）
- 实现 8 因子 Pipeline 推荐引擎（独立可插拔因子 + 三档方案输出）
- 实现 Offer 体检报告（合规/风险/违规三栏 + 因子详情 + 风险徽章）
- 实现审批说明三段式生成（方案切换 + 单段重生成 + AI 润色开关）
- 完成脱敏管道（9 策略）+ AI Provider 抽象层
- 生成 5 个标准 Excel 模板 + 行业默认规则
- 构建单文件 HTML（1135 KB）

### 技术决策
- **4 维强制切分 > 混算+系数**：画像准确性的基石，groupBy 在计算前完成，绝不用系数补偿
- **Pipeline 因子架构**：每个因子是独立对象 `{id, name, run()}`，新增因子仅需 push 一个对象
- **因子权重从数据拟合**：竞对溢价 = 竞对样本 base 中位数 / 非竞对 base 中位数 - 1，而非拍脑袋
- **table-based 热力图**替代 Chart.js 依赖，减少 1MB+ 体积
- **白盒强约束**：每条画像规律带样本数/置信度/来源 ID 列表，用户可逐条编辑

### 技术卡点
- 条件型画像的分组条件（如"来自竞对"）需要先加载竞企清单再切分，顺序依赖需注意
- 因子 delta 的三档 conservative/standard/aggressive 需要统一比例缩放（0.8x/1.0x/1.2x）

- [ ] Electron 桌面版打包测试（npm run build）

## v0.1 — 2026-04-27

### 核心迭代内容
- 从数据脱敏助手复用 Electron 主进程、build.js、afterPack.js 等基础设施
- 设计 6 页面侧边栏导航架构（对比脱敏助手的 Tab 导航，更适合多功能工具）
- 实现 14 字段薪酬解析器（字段别名映射 + 自动核算 + 分摊年限可配）
- IndexedDB 6 表数据模型（offers/historyOffers/profiles/rules/configs/activities）

### 技术决策
- 采用侧边栏固定布局而非 Tab 切换，因为 6 个页面用 Tab 会拥挤
- 存储层统一封装 CRUD + 备份/还原，预留 scope 字段供团队版扩展
- 薪酬字段定义抽象为 SALARY_FIELDS 常量，字段增减只需改一处

### 技术卡点
- 无（首版骨架搭建较顺利）
