# Offer审批助手 使用指南

> 面向薪酬 HR，零代码基础也能轻松上手

## 快速开始（3 分钟上手）

### 第一步：打开工具

双击 `Offer审批助手.html` 文件，浏览器会自动打开工具页面。

> 💡 推荐使用 Chrome / Edge 浏览器

### 第二步：导入薪酬数据

1. 点击左侧菜单「📥 薪酬导入」
2. 下载模板（14 字段标准格式），按模板填写候选人薪酬信息
3. 拖拽或点击上传 Excel
4. 系统自动校验：**绿色** = 正常，**红色** = 需关注

### 第三步：执行 Offer 体检

1. 点击「🩺 Offer体检」
2. 填写候选人上下文信息（来源公司、现薪、能力标签等）
3. 点击「执行体检」→ 系统自动出 **三档推荐方案** + **合规报告**
4. 查看因子详情，了解每个数字怎么来的

### 第四步：生成审批说明

1. 点击「✍️ 生成审批说明」
2. 选择方案档位（保守/标准/进取）
3. 系统自动生成三段式文案
4. 可以手动编辑微调
5. 点击「📋 复制全文」粘贴到审批单 / 邮件 / 企微

## 进阶功能

### 📐 规则库管理

**统一规则**：公司级通用规则（带宽检查、增幅上限等）

**我的规则**：你个人的审批偏好规则

**配置表**：
- **因子权重**：系统从历史数据拟合出默认值，你可以覆盖
- **竞企清单**：添加一线/二线竞对公司名，影响"外部竞争"因子
- **稀缺岗位**：命中后整档上浮
- **能力标签**：自定义能力标签及加成比例
- **分摊年限**：签字费/签字股票的分摊年数（默认 2 年）

### 🧬 历史 Offer 学习

这是工具的**核心差异化能力**——越用越懂你。

1. **样本规划**：点击「样本规划向导」，勾选你负责的职级×通道×国家组合
2. **导入历史**：下载模板，填入过往已审批的 Offer，批量导入
3. **一键学习**：系统自动按 4 维切分，计算每个切片的 P25/P50/P75
4. **查看画像**：每条规律都是白盒的——你能看到样本数、置信度、原始案例
5. **编辑管理**：对每条画像可以 确认 / 编辑 / 拒绝 / 删除 / 转为个人规则

> ⚠️ **样本建议**：每个组合至少 5 条样本，推荐 15 条以上

### 🔒 隐私安全

- 所有数据存在你电脑的浏览器中（IndexedDB），**不会发送到任何服务器**
- AI 润色功能默认关闭，开启后会先脱敏再调用
- 建议定期使用工作台的「导出备份」功能备份数据

## 常见问题

**Q：Excel 导入报错怎么办？**  
A：请确认使用的是标准模板，字段名和列顺序不要修改。工具支持常见别名（如"基本工资"="基本月薪"），但格式需要是 .xlsx

**Q：体检结果和我的判断不一致？**  
A：体检基于规则库 + 画像数据。你可以在「规则库」中调整规则，在「习惯画像」中编辑画像条目

**Q：推荐的薪酬数字可以修改吗？**  
A：推荐数字是参考值，不会覆盖你填写的任何数据。审批说明文案可以自由编辑

**Q：换了电脑数据会丢吗？**  
A：会。请用工作台的「导出备份」功能导出数据包，在新电脑上「导入还原」
