# Offer审批助手

> 面向薪酬管理HR的个人提效工具 —— 薪酬信息复核 → Offer合规性体检 → 多因子建议方案生成 → 审批说明产出

**当前版本**：v1.0  
**最后更新**：2026-04-27

## 核心能力

- **薪酬信息导入与校验**：14 个标准字段 Excel 导入，3 个计算项自动核算对比，分摊年限可配
- **双层规则库**：统一规则 + 个人规则，声明式 JSON 引擎（11 种运算符），配置表管理（因子权重/竞企/稀缺岗位/能力标签）
- **历史 Offer 学习**：4 维强制切分画像（国家/职级/通道/职位类型），P25/P50/P75 + 条件型规律 + 因子权重自动拟合
- **8 因子推荐引擎**：基线水位/候选人增幅/外部竞争/内部平衡/紧迫度/能力标签/岗位稀缺度/薪酬结构偏好，输出三档方案（保守/标准/进取）
- **Offer 体检报告**：合规/风险/违规三栏，每项可展开看规则来源
- **审批说明生成**：三段式文案（总包/能力匹配/预算），可选 AI 润色（默认离线）
- **完全离线**：数据零泄露，CSP 策略限制外网

## 使用方式

### 网页版（推荐分发，30-40 人团队一个文件搞定）

双击打开 `web/Offer审批助手.html` 即可使用，**无需安装任何依赖**。

### 桌面版（Electron）

```bash
cd Offer审批助手
npm install
npm start
```

### 构建单文件 HTML

```bash
npm run build-web
# 产出 → web/Offer审批助手.html（约 1.1 MB）
```

## 工作流程

```
📥 薪酬导入 → 🩺 Offer体检 + 8因子推荐 → ✍️ 审批说明 → 📋 复制/导出
     ↑                    ↑
  📐 规则库             🧬 习惯画像
```

## 隐私安全

- ✅ 完全离线运行，零网络请求
- ✅ CSP 策略限制外网
- ✅ 薪酬数据本地 IndexedDB 存储
- ✅ AI 调用前强制脱敏（9 种策略）
- ✅ 导出备份自动加密压缩

## 技术栈

- 前端：原生 HTML + CSS + JavaScript（单文件，无构建依赖）
- Excel：SheetJS（网页版） / ExcelJS（桌面版）
- 存储：IndexedDB + localStorage
- 桌面：Electron 28+
- 规则引擎：声明式 JSON + 轻量执行器
- 推荐引擎：Pipeline 架构，8 因子独立可插拔
