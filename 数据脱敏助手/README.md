# 数据脱敏助手

> 完全离线的 Excel 数据脱敏与还原工具，数据不外传

**当前版本**：v1.4.1  
**最后更新**：2026-04-20

## 两个版本，按需选择

| | 桌面版（Electron） | 网页版（单文件 HTML）✨ 新增 |
|---|---|---|
| 安装方式 | 下载 DMG 安装到 `Applications` | 双击 HTML 文件即用，免安装 |
| 平台 | 仅 macOS | 任何系统 + 任何现代浏览器 |
| 分享 | 需首次「右键→打开」绕过 Gatekeeper | 任意渠道分享，同事直接双击打开 |
| 离线 | ✅ 禁止所有网络请求 | ✅ 纯前端运行，不发任何请求 |
| 功能 | 9 种策略、自动识别、基准密钥 | 与桌面版完全对齐 |

## 功能特点

- 🔒 **完全离线** — 数据不外传，安全有保障
- 📊 **自动识别** — 智能识别列类型（人名、手机号、身份证、金额、日期等）
- 🎯 **9 种策略** — 编号替换、随机假名、格式保留替换、等比缩放、等比缩放+扰动、固定偏移、区间映射、日期偏移、不处理
- 🔑 **可逆还原** — 通过密钥文件还原脱敏数据
- 📋 **操作报告** — 脱敏/还原后展示详细的处理报告
- 📐 **公式保留** — 自动跳过含公式的单元格
- 💾 **自动记忆** — 同名列会自动应用上次的脱敏策略（网页版）

## 使用方式

### 方式一：网页版（推荐，最简单）

1. 获取 `数据脱敏助手.html`（位于 `web/` 目录下）
2. 双击文件，用默认浏览器打开
3. 开始使用

分享：把这个 HTML 文件发给同事（微信/邮件/U盘都可），对方双击即用。

### 方式二：桌面版（macOS）

1. 下载对应架构的 DMG 文件：
   - Apple Silicon (M1/M2/M3)：`数据脱敏助手-1.3.0-arm64.dmg`
   - Intel：`数据脱敏助手-1.3.0.dmg`
2. 双击 DMG 文件挂载，将 `数据脱敏助手.app` 拖入 `Applications` 文件夹
3. **首次打开**：右键点击 app → 选择「打开」→ 在弹窗中再次点击「打开」
4. 之后即可正常双击打开

### 脱敏流程

1. 拖入或选择 Excel 文件
2. 查看自动识别的列类型，按需调整脱敏策略
3. 点击「开始脱敏」
4. 导出脱敏后的 Excel 和密钥文件（密钥请妥善保管！）

### 还原流程

1. 拖入脱敏后的 Excel 文件
2. 拖入对应的密钥文件（JSON）
3. 自动还原并导出
