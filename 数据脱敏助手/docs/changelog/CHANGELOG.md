# 数据脱敏助手 - 更新日志

## v1.4.1 — 2026-04-20

- 优化：还原结果为 0 个单元格时，**显示醒目的红色失败提示**（原先会误导性地显示"还原完成"）
  - 标题变为"⚠️ 还原未成功"
  - 列出 3 种常见原因：文件拖错、密钥不配套、脱敏后 Excel 被大改（改 sheet 名 / 删列 / 改列名 / 调列序）
- 背景：此前还原失败会静默通过，用户不易察觉问题

## v1.4 — 2026-04-20

- 🎉 新增：**网页版**（单文件 HTML，约 1 MB），免安装、跨平台、可分享
  - 功能与桌面版完全对齐：9 种脱敏策略、自动列识别、基准密钥、公式保留、对比预览、操作报告
  - 纯前端运行，数据不外传，与桌面版具有同等安全性
  - 自动记忆偏好：同名列会自动应用上次的策略，无需每次重选
  - 支持密钥导入/导出（JSON），可长期维护同一套映射关系
- 桌面版与网页版并存，按需选择：
  - 桌面版：适合长期使用、固定 Mac 场景
  - 网页版：适合临时分享、多平台、无需安装

## v1.3 — 2026-04-20

- 修复：「年-月」格式（如 `2025-01`、`2025/3`、`2025年1月`）被误识别为文本的问题，现在会走日期偏移策略
- 修复：小数值列（如回款额、新客户数等数值 < 1000 的列）被 fallback 到文本映射的问题，现在保留数值特征走等比缩放
- 改进：列类型识别顺序调整，优先判断日期/年月，再判断数字

## v1.2 — 2026-04-10

- 改进：打包格式从 zip 改为 DMG 安装包，双击挂载→拖入应用文件夹即可使用
- 改进：使用 ad-hoc 自签名替代移除签名，解决通过网络传输后 macOS 提示"已损坏"的问题
- 改进：用户首次右键"打开"后即可正常使用，不再被 Gatekeeper 直接删除

## v1.1 — 2026-04-08

- 新增：脱敏/还原完成后展示「操作报告」，显示处理了哪些工作表、列、使用了什么策略
- 新增：报告中统计已处理单元格数和跳过的公式单元格数
- 优化：报告以卡片形式嵌入结果页，无需额外文件

## v1.0 — 2026-03-12

- 首个正式版本
- 支持 Excel 文件的自动列类型识别与脱敏
- 支持 8 种脱敏策略：编号替换、随机假名、格式保留替换、等比缩放、等比缩放+扰动、固定偏移、区间映射、日期偏移
- 支持密钥文件导出与数据还原
- 支持基准密钥复用（多次脱敏保持映射一致）
- 支持公式单元格自动跳过
- 支持脱敏前后对比预览
- 完全离线运行，数据不外传
- macOS 原生应用（支持 Apple Silicon 和 Intel）
